Para que possa ser feito o cadastro ate 5 contas, usei a estrutura for no case 1 para cadastrar 5 contas. Depois disso o menu segue funcionando normalmente. Ao final qaundo o usuário digita a opção 6, são exibidas as 5 contas cadastradas e o programa é encerrado. Para armazenar os dados das 5 contas, foi usado os vetores nas posições de 0 a 4 (5 dados). Em cada case, com a estrutura for o vetor é percorrido e executado o bloco de código conforme a opção digitada pelo usuário.
